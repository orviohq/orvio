# Security

This static prototype has no account system, payments, server API or telemetry. Settings stay in localStorage. Never paste tokens into issues or client code.

Report a suspected vulnerability through this repository's private vulnerability reporting feature if available. If unavailable, open a minimal issue requesting a private channel without exploit details or personal data. Do not probe unrelated infrastructure or other users.

Deployment credentials stay outside the repository and client bundle. Production deploys are maintainer-operated. No credential is required to run, build or contribute. Rotate a credential if exposed; do not merely delete it from the latest commit. Dependency updates must pass tests and build.
